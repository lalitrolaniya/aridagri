# Contributing to aridagri

Thank you for helping improve aridagri.

## Reporting a problem

Open an issue at <https://github.com/lalitrolaniya/aridagri/issues> with:

- a small reproducible example (data and code),
- what you expected and what you got (a textbook value or the output of
  another program helps),
- your R version and operating system (`sessionInfo()`).

## Suggesting a feature

Open an issue that describes the design or analysis, the reference you
follow and, if possible, a worked example with known results.

## Pull requests

1. Fork the repository and create a branch.
2. Add or update roxygen2 documentation and tests.
3. Run `devtools::check()`; it should finish with no errors, warnings or
   notes.
4. Submit the pull request with a short description of the change.
